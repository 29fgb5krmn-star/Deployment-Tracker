# Deployment Tracker

An internal web-based deployment tracking prototype designed to help
deployment teams monitor store deployment progress, technician updates,
bridge check-ins, equipment checks, and scope changes.

## Purpose

The goal of this project is to reduce manual callbacks and make deployment
updates easier to track in real time.

Instead of repeatedly contacting technicians for updates, technicians can
update their assigned deployment tasks through the tracker.

---

## Current Version

### Admin / Deployment Overview

The current prototype provides an overview of:

- Total stores
- Stores in progress
- Completed stores
- Pending stores
- Deployment night
- Assigned technician
- Store progress
- Recent technician updates
- Scope changes and cancellation notes
